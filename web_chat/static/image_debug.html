❓ 图片加载常见问题

1. 图片路径为空或不存在

检查后端日志中 [API] /api/messages 图片消息 是否包含 path 字段。

2. 图片路径正确但无法解密

检查后端日志中 [IMAGE] 相关的解密日志，确认：

  • V3 图片：是否正确计算 XOR 解密码
  • V4 图片：是否正确获取 AES 密钥

3. 图片路径是相对路径

后端会自动尝试以下路径查找：

  • 数据库目录 (DB_DIR)
  • 微信数据目录（DB_DIR 上级）
  • 项目根目录

4. 如何获取图片路径

在浏览器控制台执行：

// 查看最近加载的消息
Logger.getLogs().filter(l => l.message.includes('图片'))
