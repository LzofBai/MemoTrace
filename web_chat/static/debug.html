❓ 常见问题排查

1. 聊天列表为空

  • 检查"数据库连接"状态是否为绿色
  • 查看后端日志文件 logs/app_*.log
  • 确认 DB_DIR 和 DB_VERSION 配置正确

2. 聊天切换不生效

  • 查看浏览器控制台（F12）的日志输出
  • 检查"选择聊天"和"加载聊天记录"日志
  • 确认消息 API 返回正确的数据

3. 头像不显示

  • 查看"/api/avatar"请求的响应状态
  • 检查头像数据大小是否正常

4. 导出日志

  • 前端日志：点击"导出日志"按钮或按 Ctrl+Shift+L
  • 后端日志：查看 logs/ 目录下的 .log 文件
