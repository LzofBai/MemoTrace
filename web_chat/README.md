# MemoTrace Web 聊天界面 - 带完整日志版本

基于 MemoTrace 解密数据构建的类似微信 Web 端的聊天查看器。

## 功能特性

- ✅ **会话列表** - 显示最近聊天的好友和群聊
- ✅ **联系人列表** - 查看所有好友和群聊
- ✅ **聊天记录** - 分页加载历史消息
- ✅ **消息类型** - 支持文本、图片、语音、视频、文件、链接等多种类型
- ✅ **群成员** - 查看群聊成员列表
- ✅ **搜索** - 搜索联系人
- ✅ **聊天记录导出** - 支持 8 种格式（HTML/Markdown/Excel/Word/TXT/JSON/CSV/AI），19 种消息类型，时间/成员筛选
- ✅ **完整日志** - 详细的运行日志记录，便于问题排查

## 快速开始

### 1. 安装依赖

```bash
# 进入 web_chat 目录
cd MemoTrace/web_chat

# 安装依赖
pip install -r requirements.txt
```

依赖列表：
- Flask - Web 框架
- flask-cors - 跨域支持
- pycryptodome - 图片解密
- openpyxl - Excel 导出

### 2. 配置数据库路径

编辑 `app.py`，修改以下配置：

```python
# ==================== 配置 ====================
DB_DIR = r'J:\Github\MemoTrace_test\wxid_5e3hd0zrse6w22\Msg'  # 解密后的数据库路径
DB_VERSION = 3  # 数据库版本: 3 或 4
```

### 3. 启动服务

```bash
# 方式1: 直接启动
python app.py

# 方式2: 使用启动脚本（Windows）
start.bat
```

服务启动后，访问 http://127.0.0.1:5000

## 🔍 问题排查指南

### 问题1: 聊天列表为空

**排查步骤**:
1. 查看后端日志 `logs/app_*.log`
2. 检查数据库连接是否成功
3. 检查 `/api/contacts` 响应

**关键日志**:
```
[DB] 数据库连接成功! 共 XX 个联系人
[API] GET /api/contacts 返回 XX 个联系人
```

### 问题2: 聊天切换不生效

**排查步骤**:
1. 打开浏览器控制台 (F12)
2. 查看 `selectChat` 相关日志
3. 检查 `loadMessages` 请求和响应

**关键日志**:
```
[INFO] 选择聊天: wxid=xxx, name=xxx
[INFO] 加载聊天记录: wxid=xxx, append=false
[INFO] 聊天记录响应: code=0, msgCount=20
```

### 问题3: 头像不显示

**排查步骤**:
1. 检查 `/api/avatar/<wxid>` 请求
2. 查看头像解密日志
3. 检查网络请求状态

**关键日志**:
```
[AVATAR] 获取头像: wxid=xxx
[AVATAR] 获取成功: 1234 bytes
```

### 问题4: 图片无法显示

**排查步骤**:
1. **访问图片诊断工具**: `http://127.0.0.1:5000/static/image_debug.html`
2. **选择联系人并加载消息**
3. **查看图片路径是否存在**
   - 如果显示"无路径" - 消息对象中缺少 path 属性
   - 如果有路径但加载失败 - 路径不正确或解密失败

**关键日志**（后端 `logs/app_*.log`）:
```
[API] /api/messages 图片消息[0]: server_id=123456
[API] /api/messages 图片[0] path: Image/2025-01/xxx.dat

[API] GET /api/image?path=Image/2025-01/xxx.dat
[API] /api/image 尝试的路径: [...]
[IMAGE] 开始解密图片: ...
[IMAGE] 检测到V3格式图片，使用XOR解密
[IMAGE] 计算的解密码: 123, 文件类型: jpg
[IMAGE] ✅ V3解密成功: 5678 bytes
[API] /api/image ✅ 返回图片: 5678 bytes, type=image/jpeg
```

**常见原因**:
| 现象 | 原因 | 解决方案 |
|------|------|----------|
| 图片路径为空 | 消息对象无 path 属性 | 检查 wxManager 是否正确解析 |
| 图片不存在 | 路径不正确 | 检查 DB_DIR 配置 |
| 解密失败 | XOR/AES 密钥错误 | 检查微信版本和密钥 |
| 加载超时 | 图片太大 | 增加超时时间或压缩图片 |

## API 接口

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/test` | GET | 测试数据库连接 |
| `/api/avatar/<wxid>` | GET | 获取用户头像 |
| `/api/image?path=` | GET | 获取解密后的图片 |
| `/api/contacts` | GET | 获取联系人列表（分页） |
| `/api/contacts/search` | GET | 搜索联系人 |
| `/api/chatroom/members` | GET | 获取群成员列表 |
| `/api/messages` | GET | 获取聊天记录（分页） |
| `/api/messages/all` | GET | 获取全部聊天记录 |
| `/api/session` | GET | 获取最近会话列表 |
| `/api/stats` | GET | 获取统计信息 |

## 使用指南

### 导出聊天记录

1. **进入聊天界面** - 选择一个好友或群聊
2. **点击导出按钮** - 聊天界面右上角的 <i class="fas fa-file-export"></i> 图标
3. **配置导出选项**:
   - **导出格式**: 下拉选择 HTML、Markdown、Excel、Word、纯文本、AI训练文本、JSON、CSV
   - **时间范围**: 下拉选择"近一个月"、"近三个月"、"自定义时间"或"全部"
   - **群成员**（仅群聊）: 搜索并下拉选择成员，支持关键字搜索
   - **消息类型**: 多选下拉框选择消息类型（按住 Ctrl/Shift 可多选）
4. **点击"导出"** - 文件将自动下载到浏览器默认下载目录

**界面特点**:
- 🎯 **下拉选择框** - 统一使用下拉选择，界面简洁
- 🔍 **成员搜索** - 群聊成员支持关键字搜索
- ✓ **多选支持** - 消息类型支持多选（Ctrl+点击）
- 📊 **实时提示** - 底部显示当前选择的导出配置

**导出格式说明**:

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| HTML | 带样式的网页格式 | 在浏览器中查看，保留样式 |
| Markdown | 通用标记格式 | 导入各种笔记软件 |
| Excel | 电子表格 | 数据分析、筛选、统计 |
| Word | Word 文档 | 正式文档、打印 |
| 纯文本 | 简洁文本 | 快速阅读、编辑 |
| AI训练文本 | 特定格式文本 | 用于 AI 模型训练 |
| JSON | 结构化数据 | 程序处理、数据交换 |
| CSV | 逗号分隔值 | 表格软件兼容 |

## 调试工具

### 1. 图片诊断工具

当聊天记录中的图片无法显示时，使用此工具诊断问题：

**访问地址**: http://127.0.0.1:5000/static/image_debug.html

**功能**:
- 🔍 **快速图片测试** - 输入图片路径直接测试加载
- 📋 **消息图片分析** - 加载聊天记录分析所有图片
- 📊 **详细日志** - 查看图片加载的每个步骤

**使用步骤**:
1. 打开图片诊断工具
2. 从下拉列表选择联系人
3. 点击"加载消息并分析图片"
4. 找到显示为"无路径"或加载失败的图片
5. 点击"测试"按钮查看详细错误信息
6. 对照后端日志 `logs/app_*.log` 中的 `[IMAGE]` 标签

### 2. 通用调试页面

打开浏览器访问：
```
http://127.0.0.1:5000/static/debug.html
```

调试页面提供：
- 📊 **系统状态** - 查看后端连接、数据库状态
- 🧪 **功能测试** - 一键运行 API 测试
- 📝 **前端日志** - 查看、导出、清空前端日志
